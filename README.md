## Overview

Transportation-Of-Fish is a robust web application designed to streamline the process of transporting fish from suppliers to destinations. Built with PHP and enhanced with Hack, this project provides an efficient system for managing shipments, tracking inventory, and coordinating logistics.

## Tech Stack

- **PHP** (78%) - Core backend logic
- **Hack** (20.9%) - Enhanced PHP functionality
- **CSS** (1.1%) - Styling and UI

## Features

- Shipment management and tracking
- Route optimization
- Inventory management
- Real-time notifications
- Reporting and analytics
- Secure user authentication

## Prerequisites

- PHP 7.4 or higher
- Web server (Apache, Nginx, etc.)
- MySQL or compatible database

## Usage

### Getting Started

1. **Access the Application**
   - Open your web browser
   - Navigate to your local server address (e.g., `http://localhost/Transportation-Of-Fish`)

2. **User Authentication**
   - Login with your registered credentials
   - Default access levels: Admin, Logistics Manager, Supplier

3. **Managing Shipments**
   - Click on "Shipments" from the main dashboard
   - Click "Add New Shipment" to create a transport record
   - Fill in fish type, quantity, origin, destination, and transport date
   - Click "Save" to record the shipment

4. **Tracking Fish Transportation**
   - Navigate to "Active Shipments" to view ongoing transports
   - Update shipment status: Pending, In Transit, Delivered, or Delayed
   - Add tracking notes at each checkpoint

5. **Inventory Management**
   - Go to "Inventory" section
   - View current fish stock levels
   - Update inventory when shipments are received or dispatched

6. **Route Optimization**
   - Access "Route Planner" from the sidebar
   - Enter origin (e.g., Mwanza) and destination
   - System suggests optimal routes based on distance and time

7. **Generating Reports**
   - Click on "Reports" tab
   - Select report type: Daily, Weekly, Monthly, or Custom range
   - Export reports as PDF or CSV

8. **Real-time Notifications**
   - Notifications appear in the top-right corner
   - Alerts for: New shipments, status changes, delays, or low inventory
